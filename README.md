# География: гидросфера — тренажёр

Тренажёр по школьному учебнику географии, глава «Гидросфера»: термины и определения. Термины взяты из главы «Гидросфера» и из списка терминов про реки.

Открыть: https://fastest13.github.io/geography-hydrosphere/

## Режимы

1. **Соедини термины с определениями** — 12 случайных терминов из списка, нужно расставить определения напротив нужных понятий.
2. **Выбери определение** — термин и 5 определений: одно верное из учебника и четыре неверных. 15 случайных вопросов.

В конце — оценка от мальчика-путешественника, разбор ошибок и кнопка «Поделиться».

## Запуск

Сборка не нужна: чистые HTML, CSS и JavaScript без библиотек. Достаточно открыть `index.html` в браузере.

Данные (термины и определения) — в `js/data.js`.
