# География: гидросфера — тренажёр

Тренажёр по школьному учебнику географии, глава «Гидросфера»: термины и определения.

Открыть: https://fastest13.github.io/geography-hydrosphere/

## Режимы

1. **Соедини термины с определениями** — все термины сразу, нужно расставить определения напротив нужных понятий.
2. **Выбери определение** — термин и 5 определений: одно верное из учебника и четыре неверных. Вопросов столько, сколько терминов.

В конце — оценка от мальчика-путешественника, разбор ошибок и кнопка «Поделиться».

## Запуск

Сборка не нужна: чистые HTML, CSS и JavaScript без библиотек. Достаточно открыть `index.html` в браузере.

Данные (термины и определения) — в `js/data.js`.
